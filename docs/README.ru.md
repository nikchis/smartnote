# Документация Smartnote

Оглавление документации Smartnote: сначала руководства для пользователей, затем заметки для
разработчиков, которые собирают, упаковывают и тестируют приложение. У каждого документа есть
английская версия.

## Пользователям

- [Установка и обновление](install.ru.md): пакеты для Linux, Windows и macOS, что нужно
  семантическому поиску, обновление с 2.1.0, необратимое обновление с 2.0.x и как вернуться назад,
  где лежат файлы.
- [Настройка сервера](server-setup.ru.md): PostgreSQL и OpenSSH для сохранения и восстановления
  заметок, фраза синхронизации.
- [Яндекс Диск](yandex-disk.ru.md): вход, свой client ID, отзыв доступа.
- [Поиск](search.ru.md): слова, фразы, фрагменты кода и поиск по смыслу; строка состояния.
- [Безопасность](security.ru.md): модель угроз, усиление процессов, изоляция поискового воркера и
  то, что не защищено.
- [Ограничения](limitations.ru.md): Backup и Restore, фраза синхронизации, выход из системы,
  Яндекс Диск и возврат на 2.1.0.

## Разработчикам

- [Сборка из исходников](building.ru.md): инструменты и их версии, системные пакеты, команды `make`
  и `task`.
- [Заметки разработчика](development.ru.md): устройство кода и проверки привязок, ошибок,
  Content Security Policy и пакетов в чистом контейнере.
- [Упаковка](packaging.ru.md): что входит в каждый пакет вместе с поиском, загрузка модели и
  ONNX Runtime, лицензионные уведомления, подпись на macOS, CI.
- [Сопровождение поиска](search-maintenance.ru.md): формат хранилища, перезапуски воркера, что
  воркер может писать в журнал, AddressSanitizer и проверки в CI.
- [Ручная приёмка](manual-test.ru.md): сценарии приложения и поиска с записанными результатами.
- [Дымовой тест на Windows и macOS](smoke-windows-macos.ru.md): чек-лист для неподписанных
  пакетов.

## Заметки компонентов (только на английском)

- [tools/model/README.md](../tools/model/README.md): как готовится, собирается и загружается
  модель поиска.
- [search/testdata/protocol/README.md](../search/testdata/protocol/README.md): образцы CBOR
  протокола воркера и правила кодирования, которым следуют обе стороны.
- [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md): лицензии сторонних компонентов, которые
  входят в пакеты.
