# Ручная приёмка

Сценарии приёмки приложения и поиска с результатами, записанными для каждого пакета. Для
тестировщиков и разработчиков перед выпуском.

Сценарии спецификации (раздел 7.4). Выполните их на чистой настольной Ubuntu 26.04: один раз из
`smartnote.deb` и один раз из `smartnote-x86_64.AppImage`. Сервер — пара контейнеров: образ
OpenSSH из `internal/adapter/ssh/testdata/sshd` (пользователь `tester`, пароль `testpass`,
перенаправление TCP разрешено) и `postgres:17-alpine`, запущенный с `--network container:<sshd>` и
`listen_addresses=127.0.0.1`, так что SSH-сервер обращается к нему как к `127.0.0.1`.

Отмечайте каждый сценарий в столбце своего пакета (`.deb`, AppImage): `pass`, `fail` (с пояснением)
или `not run`. Перед сценарием 1 удалите `~/.local/share/smartnote`, чтобы начать без хранилища.

## Сценарии поиска

Сценарии спецификации поиска (раздел 12.6). Перед сценарием 21 создайте эти заметки через
**New** → **Apply changes** (вставьте тексты; в коде используйте пробелы, а не табуляцию) и
дождитесь, пока строка состояния под результатами перестанет показывать
`Semantic search is loading` или `Indexing N of M` (рядом тонкая полоса). Результат показывает название заметки, `name`
или `line N` (строки текста считаются с 1) и строку с подсвеченным совпадением.

- **Блины**: `Рецепт блинов` / `Взбить три яйца с полулитром молока, добавить стакан муки, щепотку соли и ложку сахара.` / `Жарить на горячей сковороде с двух сторон до золотистого цвета.`
- **Garden**: `Tomato seedlings` / `Water the tomato seedlings in the greenhouse every morning.` / `Open the windows when the sun is out and close them at night.`
- **Встречи**: `Встречи с клиентами переносятся на четверг.` / `Подготовить отчёт о продажах за квартал.` / `Позвонить поставщику по поводу задержки.`
- **Running log**: `She runs five kilometres every day.` / `Prepare the quarterly sales report for the board.` / `The report on sales is due next quarter.`
- **Retry code**: функция Go из 10 строк: `func retryBackoff(attempt int) time.Duration {`, `if attempt == 0 {`, `return time.Second`, `}`, `delay := baseDelay << attempt`, `if (delay > maxDelay) {`, `return maxDelay`, `}`, `return delay`, `}`.
- **Journal**: 100 строк `Entry NN: routine check, nothing unusual today.`, кроме строки 91 `Entry 91: the old lighthouse keeper sent a postcard from the coast.`; текст требует прокрутки.

Модель выключена, если её каталога нет: закройте Smartnote и переименуйте `usr/share/smartnote/model`
(`/usr/local/share/smartnote/model` для `.deb`, `squashfs-root/usr/share/smartnote/model` для
распакованного AppImage) в `model.off`; после проверки верните имя. Процессор без AVX2 даёт тот же
эффект. Воркер — это процесс `smartnote-search`; завершите его командой
`kill -9 $(pidof smartnote-search)` (`pkill -x` не находит имя, которое ядро обрезает до 15
символов).
