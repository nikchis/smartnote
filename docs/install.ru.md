# Установка и обновление

Как установить Smartnote на Linux, Windows и macOS, что нужно от системы семантическому поиску,
как обновиться с 2.2.x, 2.1.0 и 2.0.x и где приложение хранит свои файлы. Для пользователей.

Пакеты — на [странице выпусков](https://github.com/nikchis/smartnote/releases). Они не подписаны,
поэтому Windows и macOS предупреждают перед первым запуском.

## Ubuntu (.deb)

Ubuntu 26.04, amd64, файл `smartnote_<версия>_amd64.deb`:

```
sudo apt install ./smartnote_<версия>_amd64.deb
```

Команда подтягивает GTK 4 и WebKitGTK 6.0.

## Ubuntu (AppImage)

Ubuntu desktop, amd64, файл `Smartnote-<версия>-x86_64.AppImage`: сделайте его исполняемым (`chmod +x`) и
запустите. Минимальной системе нужны ещё `libegl1 libgles2 libfontconfig1 libfribidi0
libharfbuzz0b bubblewrap xdg-dbus-proxy`; в любой настольной Ubuntu они есть.

## Windows

Windows 10/11, файл `Smartnote-<версия>-windows-amd64.msi`. SmartScreen показывает «Windows
protected your PC»: выберите **More info**, затем **Run anyway**.

Пакет устанавливает Smartnote для текущего пользователя в `%LOCALAPPDATA%\Programs\Smartnote` без
прав администратора и добавляет ярлыки в меню «Пуск» и на рабочий стол. Ему нужен Microsoft Edge
WebView2 Runtime, который есть в Windows 11 и обновлённой Windows 10; без него пакет отказывается
устанавливаться и называет страницу, откуда скачать Runtime. Более новый пакет заменяет
установленную версию. Smartnote удаляется в **Параметры → Приложения**; заметки
(`%APPDATA%\smartnote`) и данные WebView2 (`%APPDATA%\smartnote.exe`) остаются.

Семантическому поиску нужен Microsoft Visual C++ Redistributable (x64), который есть в большинстве
систем; без него работает только полнотекстовый поиск.

## macOS

macOS 13+ на Apple Silicon (arm64), файл `Smartnote-<версия>-macos-arm64.dmg`. Пакета для Mac на Intel нет: библиотека
ONNX Runtime для поиска закреплена только для Apple Silicon ([Упаковка](packaging.ru.md)).

Gatekeeper не открывает неподписанное приложение: перетащите Smartnote в Applications, затем либо
после первой попытки откройте **System Settings → Privacy & Security** и нажмите **Open Anyway**,
либо выполните

```
xattr -dr com.apple.quarantine /Applications/smartnote.app
```

## Требования семантического поиска

На компьютерах x86-64 семантическому поиску нужен процессор с AVX2, на Windows — ещё и Visual C++
Redistributable (см. выше). Без них Smartnote работает, полнотекстовый поиск тоже, а строка
состояния поиска показывает `Semantic search unavailable` ([Поиск](search.ru.md#строка-состояния)).

## Обновление с 2.2.x

2.3.0 хранит локальное хранилище в том же формате 2, поэтому обновление не требует действий:
заметки, настройки и вход в Яндекс Диск сохраняются. 2.3.0 добавляет хранилище
[Google Drive](google-drive.ru.md), русский интерфейс и политику конфиденциальности в приложении (см.
[Интеграция с рабочим столом](#интеграция-с-рабочим-столом)). При первой разблокировке 2.3.0
добавляет в `local.db` две таблицы: для входа в Google и для незавершённой загрузки на Google Drive;
2.2.x их не читает.

При возврате на 2.2.x `local.db` остаётся читаемым, заметки и вход в Яндекс Диск на месте. 2.2.x не
знает Google Drive: если он выбран, подключение завершается ошибкой, а в Settings версии 2.2.x можно
выбрать другое хранилище. Сохранение Settings в 2.2.x стирает ваши собственные client ID и client
secret Google. После возврата на 2.3.0 введите ту же пару снова: сохранённый вход в Google снова
заработает, если Google его не отозвал, а новый вход понадобится только с другим клиентом. 2.2.x не
читает `prefs.json` и всегда работает на английском.

## Обновление с 2.1.0

2.2.0 хранит локальное хранилище в том же формате 2, поэтому обновление не требует действий.
Настройки сервера сохраняются; **Settings** показывает их под **SSH + PostgreSQL**. При возврате на
2.1.0 `local.db` остаётся читаемым, но настройки Яндекс Диска или **None (local only)** может
понадобиться очистить в Settings версии 2.1.0: см. [Ограничения](limitations.ru.md).

## Обновление с 2.0.x

2.1.0 добавляет локальный поиск и хранит локальное хранилище в формате 2, где есть зашифрованные
поисковые данные заметок. Первая разблокировка в 2.1.0 и новее окончательно преобразует
`local.db`, и 2.0.x после этого отказывается его открывать с сообщением «Data was created by a
newer version of Smartnote.». Обратного преобразования нет.

Чтобы вернуться на 2.0.x:

1. Сохраните заметки на свой сервер в 2.1.0 (**Save**) или новее (**Backup**).
2. В 2.0.x начните с нового локального хранилища (уберите `local.db` в другое место).
3. Заново настройте подключение в **Settings**. SSH-ключ тоже хранится в `local.db`: импортируйте
   файл своего ключа или создайте новый ключ и разрешите его на сервере.
4. **Restore**.

## Где лежат данные

| Система | Локальное хранилище (`local.db`) | Журнал ошибок (`smartnote.log`) |
|---|---|---|
| Linux | `$XDG_DATA_HOME/smartnote` (`~/.local/share/smartnote`) | `$XDG_STATE_HOME/smartnote` (`~/.local/state/smartnote`) |
| Windows | `%APPDATA%\smartnote` | `%LOCALAPPDATA%\smartnote` |
| macOS | `~/Library/Application Support/smartnote` | `~/Library/Logs/smartnote` |

В журнале только ошибки — без паролей, фразы синхронизации, ключей, названий и текстов заметок и
строки подключения.

Язык интерфейса хранится в `prefs.json` рядом с `local.db`, открытым текстом: он нужен до
разблокировки и не секретен. Пока язык не переключали, Smartnote следует языку системы (русский для
русской системы, иначе английский) и такого файла не создаёт.

На Linux логотип для заголовка окна записывается в `$XDG_CACHE_HOME/smartnote/icons`
(`~/.cache/smartnote/icons`), потому что GTK 4 берёт значки окон только из темы значков; больше там
ничего нет, а после удаления файл записывается снова.

## Интеграция с рабочим столом

- Одновременно работает только один Smartnote: повторный запуск выводит открытое окно на передний
  план.
- Идентификатор приложения — `com.nikchis.smartnote`; `.deb`, `.rpm` и AppImage несут ярлык
  `com.nikchis.smartnote.desktop` под этим именем, поэтому рабочие столы на Wayland показывают
  логотип у окна, и метаданные AppStream для центров приложений.
- Интерфейс использует шрифт Liberation Sans (`fonts-liberation`), заметки — DejaVu Sans Mono 13pt
  (`fonts-dejavu-core`); оба — зависимости пакетов.
- Цвета — тёмная тема v1, какую бы тему ни предпочитала система.
- Интерфейс на английском или русском. Кнопка **EN**/**RU** справа от строки поиска на главном
  экране показывает текущий язык и переключает на другой: экраны, диалоги, подсказки, сообщения,
  прогресс передач, страницы браузера при входе и заголовки файловых диалогов. Технический текст
  ошибок SSH и PostgreSQL остаётся таким, каким его дают библиотеки.
- Кнопка со щитом, последняя справа, открывает **Политику конфиденциальности** (**Privacy Policy**)
  на языке интерфейса. Это копия, хранящаяся в приложении, поэтому она открывается без сети; ссылки
  из неё открываются в браузере.

Дальше, если заметки нужно сохранять: [Настройка сервера](server-setup.ru.md) для своего сервера,
[Яндекс Диск](yandex-disk.ru.md) или [Google Drive](google-drive.ru.md).
