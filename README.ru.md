# Smartnote

Блокнот для личных записей под Linux, Windows и macOS. Заметки хранятся в зашифрованном локальном
хранилище; по желанию их можно сохранять на собственный сервер PostgreSQL, доступный по SSH, или
на Яндекс Диск и восстанавливать оттуда; сервер и Диск видят только шифротекст. Версия 2 —
переписанное на Go, Wails v3 и Svelte приложение на Delphi
(ветка [`v1`](https://github.com/nikchis/smartnote/tree/v1)).

## Возможности

- Заметки зашифрованы локально ключом, который защищён вашим паролем; у заметок есть история версий.
- Необязательное резервное копирование и восстановление через ваш PostgreSQL по SSH; сервер видит
  только шифротекст.
- Необязательное резервное копирование и восстановление через Яндекс Диск после входа в аккаунт
  Яндекса; см. [Яндекс Диск](docs/yandex-disk.ru.md).
- Локальный полнотекстовый и семантический поиск на русском и английском, в том числе по коду;
  ничего не покидает устройство.

## Скачать

Пакеты — на [странице выпусков](https://github.com/nikchis/smartnote/releases); они не подписаны.
Порядок установки и требования описаны в разделе [Установка и обновление](docs/install.ru.md).

| Система | Пакет |
|---|---|
| Ubuntu 26.04 (amd64) | `smartnote_<версия>_amd64.deb` |
| Ubuntu desktop (amd64) | `Smartnote-<версия>-x86_64.AppImage` |
| Windows 10/11 | `Smartnote-<версия>-windows-amd64.msi` |
| macOS 13+ на Apple Silicon | `Smartnote-<версия>-macos-arm64.dmg` |
